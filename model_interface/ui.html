model-interface · live record

Connect with the operator's key to see every agent, or with an agent's key to see that agent.

Every call that passes through the gateway appears here as it streams: its agent and session on the left, its blocks in the middle, opening, growing and closing in real time.

Point an SDK at this address with an agent key, name the model as the provider names it, add an X-Session header, send a call with stream: true, and watch.

The red switches are the killswitch: one for the gateway, one per agent, one per session. On cuts every running stream beneath it and refuses new calls until it is turned off.

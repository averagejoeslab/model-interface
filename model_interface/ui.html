Connect with the operator's key to see every agent, or with an agent's key to see that agent.

Every call that passes through the gateway is tapped as it flows. Pick a session: the wire at the top shows each stream on the session's clock, its pieces as segments and every delta as a tick; the transcript reads the session back; the record shows the exact document growing.

Point an SDK at this address with an agent key, name the model as provider/model, add an X-Session header, send a call with stream: true, and watch. Rules run in the loop at three moments; what they trip shows here as it happens.
